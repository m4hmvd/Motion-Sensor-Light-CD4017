## 📌 Description
Automatic motion-activated lighting system using IR proximity sensor and CD4017 decade counter IC.

## 🔧 Components Used
- IR Obstacle Sensor
- CD4017 Decade Counter IC
- BC557 & BC547 Transistors
- 9V Relay
- LEDs, Resistors, Capacitors

## 📁 Project Contents
- `Hardware/` - Circuit design files
- `Images/` - Circuit diagrams and photos
- `Documentation/` - Project report and datasheets

## 🎯 Features
- Motion detection using IR sensor
- Relay-based load control
- No microcontroller required
- Low power consumption
